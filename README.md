### Zomato Dataset Exploratory Data Analysis

Exploratory Data Analysis (EDA) project on the Zomato restaurant dataset to understand restaurant ratings, distributions, and patterns across different countries.

## Overview

This project analyzes the Zomato restaurant dataset to extract meaningful insights about:
- Restaurant ratings distribution
- Country-wise transaction patterns
- Top cuisines
- Online delivery availability
- City-wise distribution

## Technologies Used

- **Python**
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computing
- **Matplotlib** - Data visualization
- **Seaborn** - Statistical data visualization

## Key Findings

| Insight | Finding |
|---------|---------|
| Top Country | India (highest number of transactions) |
| Top 3 Countries | India, United States, United Kingdom |
| Rating Range | Most ratings between 2.5 to 3.4 |
| Online Delivery | Available in India and UAE |
| Top Cuisines | North Indian, Chinese, Fast Food (based on analysis) |

1. **Missing Values Detection** - Identified columns with null values
2. **Numerical Variables Exploration** - Statistical summary
3. **Categorical Variables Analysis** - Country, City, Cuisines
4. **Relationship Between Features** - Rating vs Country, etc.
5. **Visualizations** - Pie charts, bar plots, heatmaps
